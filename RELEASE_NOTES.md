# Pip 1.10.0

The notch doesn't have to sit dead centre any more.

## New

- **Drag Pip along the top of the screen.** Grab Pip or the notch and slide it
  left or right; it stays where you leave it, even after a restart, a
  resolution change or a move to another screen. Drop it near the middle and it
  snaps back to the centre.

## Better

- **Clicks still work as they did.** A press that doesn't move is still a
  tickle for Pip or a pin for the notch — they now happen as you let go, so a
  press can become a drag. Nothing moves while Settings or the activity panel
  is open.

Thanks to @aymanokas for this one (#4).

## Install

Pip finds this one itself and offers **Restart now**.

Otherwise download `Pip-Setup-1.10.0.exe` below and run it once; it installs for
your user only. The installer isn't code-signed yet, so Windows SmartScreen may
warn you: choose **More info → Run anyway**.

Requires Windows 10 or 11 (x64).
