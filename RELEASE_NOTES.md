# Pip 1.9.0

Pip can be whoever you like now, and Settings got a tidy-up to make room.

## New

- **Pick your creature.** Settings → **Appearance** → **Creature**: the
  original **Sprout**, a ginger **Kitty** with a curling tail, a snow-white
  **Bunny** with long floppy ears, a caramel **Puppy** with an eye patch, or a
  **Robot** whose face glows on a little visor. Each is its own animal, not the
  sprout in a costume, and every mood still reads: ears droop when it naps and
  flick while Claude works, tails swish and wag, the robot's antenna blinks.
  Your helpers become the same creature, in their own colours.

- **Dress it up.** Eleven colours (picking a creature picks its usual coat,
  and you can change it after), always-rosy cheeks, and something to wear: a
  bow, a flower, a crown, a party hat or glasses.

- **Notch themes.** Midnight (as before), Berry, Forest, Ocean and Cocoa, for
  the notch and the panels inside it.

## Better

- **Settings is tidier.** Three tabs (General, Appearance, Claude Code) of small
  cards, and none of them scrolls. The screen choice is one dropdown, game
  mode's extras only show while it's on, and updates live in a footer that's
  always there. If Pip's hooks aren't installed, the Claude Code tab shows a
  red dot so you can't miss it.

Thanks to @aymanokas for this one (#2).

## Install

Pip finds this one itself and offers **Restart now**.

Otherwise download `Pip-Setup-1.9.0.exe` below and run it once; it installs for
your user only. The installer isn't code-signed yet, so Windows SmartScreen may
warn you: choose **More info → Run anyway**.

Requires Windows 10 or 11 (x64).
