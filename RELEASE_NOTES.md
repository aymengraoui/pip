# Pip 1.8.0

1.7.0 taught the notch to follow you to whichever screen you are working on.
Some of you would rather it stayed put, so now it can.

## New

- **Pin Pip to one screen.** With two or more displays plugged in, Settings
  gets a **Screen** picker: **Follow my work** (the 1.7.0 behaviour, still the
  default) or any screen you have. Picking one moves the notch at once.

- **Unplugging a pinned screen doesn't lose Pip.** It follows you until that
  screen comes back, then returns to it on its own. The picker always lists
  what is actually plugged in right now.

Thanks to @aymanokas for this one (#1).

## Install

Pip finds this one itself and offers **Restart now**.

Otherwise download `Pip-Setup-1.8.0.exe` below and run it once; it installs for
your user only. The installer isn't code-signed yet, so Windows SmartScreen may
warn you: choose **More info → Run anyway**.

Requires Windows 10 or 11 (x64).
