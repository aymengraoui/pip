# Pip 1.0.0

The first release of Pip, a tiny companion that lives in a notch at the top of your Windows screen and keeps you company while Claude Code works.

## What it does

- **Follows your Claude Code sessions.** Pip thinks, works (with a propeller leaf), bounces and glows orange when Claude needs your approval, throws confetti when it's done, and gets dizzy when something fails. Hover the notch to see every session.
- **Shows your subagents.** Every agent Claude Code spawns pops out of Pip as a colored sproutling, shows the tool it's using, and poofs away when it finishes.
- **Is fun to have around.** It follows your cursor, whistles, yawns and naps when idle. Click it to tickle, wiggle the mouse over it to pet, poke it too much and it gets dizzy.
- **Stays out of your games.** When a game or any fullscreen app is in front, Pip hides and stops everything; Task Manager shows 0 % CPU. The rest of the time it uses an adaptive frame rate and a window sized to what it draws.
- **Settings in the notch.** Start with Windows, sounds, game mode, extra games, and Claude Code hooks, all from the gear button.

## Install

1. Download `Pip-Setup-1.0.0.exe` below and run it. It installs for your user only.
2. The installer isn't code-signed yet, so Windows SmartScreen may warn you: choose **More info → Run anyway**.
3. Open the gear in the notch and click **Install** next to Claude Code hooks (needs Node.js on PATH). New Claude Code sessions will show up in Pip.

Requires Windows 10 or 11 (x64).
